ToolBar2 is a desktop toolbar for menus, top-level launchers, logo actions, web search, drag-and-drop shortcuts, and per-monitor toolbar profiles.

Tip Use the search field on the left for fast filtering. Searches for padding, logo, web search, and dropped files are especially useful when learning the toolbar layout options.
Getting Started

Typical setup

1. Open Toolbar Settings... from the tray or toolbar.

2. Adjust Appearance and Behavior.

3. Configure the Logo tab and the Menus tab.

4. Press Save to keep the changes or Cancel to restore the previous live toolbar state.

Default startup layout ToolBar2 starts with one top-level menu named Tools, the logo visible, the Settings gear shown, and the Web Search bar turned off.

The toolbar and Settings window both support live preview. Most settings apply immediately while the Settings window is open. Cancel rolls the visible toolbar back to the previously saved configuration.

Appearance

Colors and Transparency

Toolbar background

Controls the base color behind the entire toolbar.

Choices: any color selected from the color picker.

Default: #202020.

Example: set a darker gray to make menu buttons stand out more clearly.

Interaction: combined with Toolbar background opacity.

Button background

Base button fill used by top-level menu buttons and standard controls.

Choices: any color.

Default: #3b3b3b.

Example: use a muted blue to match brand colors.

Button hover

Hover fill for top-level buttons and interactive text fields.

Choices: any color.

Default: #505050.

Example: brighten hover slightly so button focus is obvious without overwhelming the toolbar.

Button text

Foreground text color used on toolbar buttons and fields.

Choices: any color.

Default: #ffffff.

Example: use near-white when the button background is dark.

Menu background

Background color for drop-down menus.

Choices: any color.

Default: #2c2c2c.

Example: match it to your toolbar or make it slightly darker for separation.

Menu text

Foreground color for menu items.

Choices: any color.

Default: #ffffff.

Example: pair bright text with dark menu backgrounds for readability.

Border color

Border color shared by toolbar buttons, menus, and text fields.

Choices: any color.

Default: #606060.

Example: use a lighter border when you want a crisp toolbar outline.

Toolbar background opacity

Opacity for the toolbar surface only.

Range: 0.10 to 1.00.

Default: 0.95.

Example: lower it to 0.75 for a semi-transparent look.

Interaction: the toolbar background color is converted to RGBA using this value.

Size and Spacing

Toolbar height

Requested total toolbar height.

Range: 16 to 240.

Default: 40.

Example: use 32 for a compact toolbar or 64 for larger buttons.

Interaction: buttons, logo, icons, text, Web Search field, gear, and Exit button automatically shrink to fit. Top/bottom edge padding may also be reduced automatically.

Auto toolbar width

Makes the toolbar span the current monitor width automatically.

Choices: on or off.

Default: off.

Example: enable it for a full-width toolbar on each selected monitor.

Interaction: when enabled, Toolbar width is ignored.

Toolbar width

Requested width when automatic width is turned off.

Range: 300 to 3000.

Default: 1000.

Example: set 1400 to make room for more top-level items without stretching across the full monitor.

Horizontal alignment

Positions a custom-width toolbar on the monitor.

Choices: Left, Center, Right.

Default: Center.

Example: choose Right for a narrow toolbar anchored to the upper-right corner.

Interaction: only affects custom-width mode.

Horizontal offset

Moves a custom-width toolbar left or right in pixels.

Range: -3000 to 3000.

Default: 0.

Example: use 32 to nudge a centered toolbar slightly right.

Button height

Requested top-level button height.

Range: 12 to 96.

Default: 36.

Example: reduce it to 28 on a compact toolbar.

Interaction: the effective button height is automatically reduced when the toolbar is too short.

Corner radius

Rounds the corners of standard toolbar buttons and fields.

Range: 0 to 24.

Default: 6.

Example: use 0 for square buttons or 12 for softer corners.

Interaction: the effective radius is capped at half the effective button height.

Left/right edge padding

Inside spacing at the far left and right edges of the toolbar.

Range: 0 to 100.

Default: 8.

Example: increase it to 20 for more breathing room at the ends.

Top/bottom edge padding

Equal inside spacing at the top and bottom of the toolbar.

Range: 0 to 60.

Default: 4.

Example: use 10 for a taller visual margin around buttons.

Interaction: ToolBar2 automatically reduces the effective padding if the toolbar is too short to fit the controls.

Menu button spacing

Spacing between top-level menus, top-level launchers, and the Web Search bar.

Range: 0 to 50.

Default: 10.

Example: set 4 for a denser toolbar layout.

Top menu position

Controls where the top-level toolbar buttons appear inside the toolbar.

Choices: Left, Center, Right.

Default: Center.

Example: choose Left when you want menus aligned near the logo.

Toolbar Controls

Show Settings gear

Shows the gear button on the toolbar.

Choices: on or off.

Default: on.

Example: turn it off on a shared kiosk monitor but keep settings reachable from the tray.

Show Exit button

Shows the red Exit button on the toolbar.

Choices: on or off.

Default: off.

Example: enable it if you want a visible close control on the toolbar.

Show Web Search bar

Shows or hides the built-in top-level Web Search bar.

Choices: on or off.

Default: off.

Example: enable it to get a movable search field between top-level items.

Interaction: when enabled it appears in toolbar order and in the Menus tree as Web Search Bar.

Search bar width

Requested width of the Web Search bar.

Range: 100 to 500.

Default: 180.

Example: increase it to 260 when you type longer searches.

Placeholder text

Placeholder text shown inside the Web Search bar.

Choices: any text.

Default: Search the web....

Example: use Search docs and sites... for a custom workflow.

Search engine

Provider used when you press Enter in the Web Search bar.

Choices: Google, Bing, DuckDuckGo, Yahoo, Custom.

Default: Google.

Example: choose DuckDuckGo if you prefer a different search provider.

Custom search URL

URL template used only when Search engine is set to Custom.

Requirement: must contain {query}.

Default: blank.

Example: https://example.com/search?q={query}.

Interaction: ToolBar2 warns instead of searching if the template is blank or missing {query}.

Behavior

Toolbar mode

Controls how toolbar configurations are shared across monitors.

Choices: One monitor, Selected monitors - same toolbar, All connected monitors - same toolbar, Selected monitors - unique toolbar on each.

Default: One monitor.

Example: use the unique-toolbar mode when each monitor needs different menus or logo actions.

Trigger height

Height of the top-edge activation zone used to reveal the toolbar.

Range: 1 to 30.

Default: 5.

Example: increase it to 10 if revealing the toolbar feels too precise.

Hide delay (ms)

Delay before the toolbar hides after the pointer leaves and nothing is holding it open.

Range: 100 to 5000.

Default: 750.

Example: use 1500 if you want more time to re-enter the toolbar.

Animation duration (ms)

Slide animation duration when the toolbar shows or hides.

Range: 0 to 2000.

Default: 200.

Example: set 0 for instant movement or 400 for a smoother reveal.

Open toolbar menus on hover

Allows top-level menus to open from hover instead of requiring only a click.

Choices: on or off.

Default: on.

Example: turn it off if you prefer explicit clicks while moving across the toolbar.

Hover delay (ms)

Delay before a hovered toolbar menu opens when hover opening is enabled.

Range: 0 to 1000.

Default: 200.

Example: use 0 for immediate hover opening.

Confirm before exiting

Adds a confirmation prompt before the toolbar exits completely.

Choices: on or off.

Default: off.

Example: enable it to avoid closing the toolbar accidentally from the Exit button or tray menu.

Start ToolBar2 with Windows

Registers ToolBar2 to start when you sign in to Windows.

Choices: on or off.

Default: off.

Example: enable it on your main workstation so the toolbar is ready after sign-in.

Interaction: the checkbox is only available when the compiled executable supports startup registration.

Profiles

ToolBar2 stores a runtime configuration plus saved toolbar profiles. In per-monitor mode, each selected monitor can have its own toolbar profile while still sharing the same application-level settings and user-profile metadata.

Useful profile actions

Copy Toolbar From... copies another monitor toolbar into the current monitor profile.

Reset This Toolbar resets only the currently selected monitor toolbar profile.

Saved Profiles lets you keep reusable toolbars for import, export, and reassignment.

Note Save keeps the current live preview. Cancel restores the last saved runtime configuration, including toolbar order, logo settings, and the Web Search bar position.
Logo

Appearance

Show logo

Shows or hides the logo at the left side of the toolbar.

Choices: on or off.

Default: on.

Logo image path

Path to the current logo image.

Choices: imported image file, pasted image, dropped image, or web image URL.

Default: img/ToolBar2.png.

Example: use Restore Default Logo to go back to the bundled logo.

Logo height

Requested logo height.

Range: 16 to 200.

Default: 48.

Interaction: the displayed height is automatically reduced when the toolbar is too short or top/bottom edge padding leaves less room.

Maximum width

Caps the displayed logo width.

Range: 32 to 600.

Default: 640 in the validated config, with the editor itself clamped to 32 to 600.

Example: lower it if a wide logo crowds nearby menus.

Logo opacity

Opacity of the logo image only.

Range: 0.10 to 1.00.

Default: 1.00.

Preserve aspect ratio

Keeps the logo image from stretching when it is resized.

Choices: on or off.

Default: on.

Tooltip

Tooltip text shown when the pointer rests on the logo.

Choices: any text.

Default: ToolBar2 by Ron.

Left-click action

Controls what happens when the logo is left-clicked.

Choices: Do nothing, Open logo menu, Open first enabled item, Custom launcher.

Default: Do nothing.

Interaction: Custom left-click launcher matters only when the action is Custom launcher.

Custom left-click launcher

Opens the standard launcher editor for a logo-specific launcher.

Choices: any launcher item.

Example: point the logo at a documentation site or a frequent local tool.

Logo Menu

The Logo tab also has a menu editor. It supports nested menu items under the logo and uses the same building blocks as the main Menus tab: launchers, submenus, headings, and separators. The logo menu is independent from the top-level toolbar menus.

Menus

The Menus tab manages the top-level toolbar order plus nested menu content. The tree can contain normal top-level menus, top-level launchers, and the special built-in Web Search Bar row when it is enabled.

Top-level item types

Menu: a button that opens a drop-down list.

Top-level launcher: a button that launches directly.

Web Search Bar: the built-in search field; movable but not stored in config["menus"].

Menu name

Display text for a top-level menu button.

Default: new top-level menus use Menu.

Enabled

Shows whether a top-level menu button is active.

Choices: on or off.

Interaction: disabled menus remain in the tree and toolbar but appear italicized or dimmed.

Icon

Custom icon path for a top-level menu.

Choices: imported image, dropped image, default icon, or removed icon.

Icon only

Shows only the menu icon when a custom or default icon is available.

Choices: on or off.

Default: off.

Use custom toolbar button colors

Lets a top-level menu override the global button colors.

Choices: on or off.

Default: off.

Button background / Button hover / Button text / Button border

Per-menu colors available when custom toolbar button colors are enabled.

Choices: any color.

Interaction: Reset Colors to Global Defaults restores these fields to the current global Appearance colors.

Headings and separators are only valid inside menus or submenus. Submenus can contain more nested items. Drag-and-drop menu editing remains enabled for normal menu content.

Launchers

Display name

Name shown for the launcher button or menu item.

Default: blank launchers resolve to Launcher on save, and some targets can auto-fill the name until you edit it manually.

Target

File path, folder path, website URL, or command target for the launcher.

Requirement: must not be empty when saving.

Interaction: Browse opens a file picker for most target types, a folder picker for Folder, and leaves website or command entry manual.

Target type

Determines how the target is treated.

Choices: Auto Detect, Program, Command Script, PowerShell Script, Python Script, File, Folder, Website.

Default: Auto Detect.

Arguments

Additional command-line arguments passed to the launcher target.

Choices: any text.

Example: add a document path or command option for a script.

Working directory

Folder used as the launcher working directory.

Choices: any existing folder path.

Python execution mode

Controls how Python scripts start.

Choices: Automatic, Console Python, Windowed Python.

Default: Automatic.

Interaction: only enabled when Target type is Python Script.

Enabled

Turns an individual launcher on or off.

Choices: on or off.

Default: on.

Accept dropped files

Allows the launcher to receive dragged local files. For folder targets the UI wording becomes Accept dropped items.

Choices: on or off.

Default: off.

When items are dropped

Folder-only action for dropped content.

Choices: Move to this folder, Copy to this folder, Ask each time.

Default: Move to this folder.

Icon

Custom icon for the launcher.

Choices: imported image, EXE icon, web image URL, dropped image, or target icon fallback.

Interaction: top-level launchers also support Icon only and Use custom toolbar button colors.

Folder Menus

Folder menus are top-level menu buttons backed by a folder path. ToolBar2 can scan folders, build menu entries from the contents, and keep those top-level buttons in the same ordering system as menus, top-level launchers, and the Web Search bar.

Tip If a folder menu points to a folder that becomes unavailable, ToolBar2 keeps the toolbar button but shows the folder as unavailable instead of crashing.
Web Search Bar

The Web Search bar is a built-in top-level toolbar item. It is not stored in config["menus"], but it participates in toolbar order, the Menus tree, drag-and-drop positioning, and Move Left/Right actions.

Search flow

1. Type text into the Web Search bar.

2. Press Enter.

3. ToolBar2 trims the text, URL-encodes it, builds the selected provider URL, and opens it in your default Windows browser.

4. The field clears only after the browser accepts the URL.

Custom URL rule Custom search URLs must include {query}. ToolBar2 warns instead of searching if the template is invalid.

Provider URLs

Google: https://www.google.com/search?q={query}

Bing: https://www.bing.com/search?q={query}

DuckDuckGo: https://duckduckgo.com/?q={query}

Yahoo: https://search.yahoo.com/search?p={query}

Drag and Drop

You can drag files, folders, apps, scripts, HTML pages, and website shortcuts into ToolBar2. External drops open the existing dropped-items workflow so you can decide whether to add the items at the top level or inside a destination menu or submenu.

Top-level blank toolbar drops still use the dropped-items dialog. The blank-area Add Launcher... command is separate and opens the launcher editor directly.

Accept Dropped Files

Launchers can optionally accept dropped local files. Folder launchers expose the folder-specific drop action choices and can move, copy, or ask each time. Non-folder launchers can still receive dropped files when configured, usually to pass those files to the target program or script.

Multi-Monitor Toolbars

Use the Behavior tab monitor tools to identify displays, select which monitors participate, and decide whether those monitors share a toolbar or keep unique toolbar profiles.

Assign Imported Toolbar... helps place imported profiles onto known monitors. Unique per-monitor toolbars preserve their own menus, logo settings, and Web Search bar position.

Import and Export Profiles

ToolBar2 supports importing and exporting toolbar profile packages. This includes toolbar appearance, behavior, logo configuration, menus, launchers, and the saved Web Search bar settings and position.

Compatibility Older configs that still contain customer-search fields load without errors. ToolBar2 migrates them to the current Web Search bar settings and ignores the obsolete path field.
Troubleshooting
Help will not open If help/index.html is missing or your browser rejects the local file URL, ToolBar2 shows a warning dialog instead of raising an exception.
Toolbar looks cramped Reduce Toolbar height, Button height, or Top/bottom edge padding conflicts by lowering the requested values. ToolBar2 already auto-shrinks controls, but extreme combinations still reduce usable space.
Web Search warning If Custom search does nothing, verify the URL includes {query}.
Keyboard and Mouse Actions

F2

Rename the selected item in the Menus tree when renaming is allowed.

Delete

Delete the selected tree item when deletion is allowed.

Ctrl+D

Duplicate the selected tree item when duplication is allowed.

Double-click

Edits a top-level menu, launcher, top-level launcher, or the special Web Search Bar row in the Menus tree.

Right-click the Web Search bar

Opens actions for Paste, Select All, Edit Search Bar..., Move Left, Move Right, and Hide Search Bar.
